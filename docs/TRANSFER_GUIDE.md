# 移轉到其他主機

## 最簡單的方式

1. 複製整個專案資料夾、使用本機的 `九九怪獸大對決_移轉包.zip`，或從 GitHub 儲存庫下載原始碼。
2. 在新主機解壓縮後，保持 `index.html`、`css/`、`js/`、`assets/`、`docs/` 的相對位置。
3. 用瀏覽器直接開啟 `index.html`。不需要 Node.js、套件安裝、網路或伺服器。
4. 從首頁開始一局，確認按鈕、角色、雙人答題、攻擊、倒數與結算。

支援目標：Windows、Mac、Chromebook 與 iPad 的現代瀏覽器。建議橫向及全螢幕。iPad 上可透過「檔案」App 將整個資料夾保存到本機，再開啟 `index.html`；若瀏覽器不允許從檔案 App 載入相鄰 CSS/JS，可改用受管理的本機靜態檔案服務，程式本身不需修改。

## 移轉時要知道的資料

程式碼與怪獸素材全在專案資料夾裡。`localStorage` 的設定**不會**隨檔案移轉，也不會在不同瀏覽器之間同步。換主機後請重新選擇教師設定、音效、BGM、角色及上次遊戲模式。學生名稱和錯題資料不是永久保存資料。

## 新主機檢查清單

- 首頁、設定、選角、VS、倒數、遊戲、結果都能依序進入。
- 遊戲頁頂部計時／暫停列在三欄場地上方，沒有跑到左側或把畫面推到右側。
- 玩家 1 的 Q/W/E、玩家 2 的 I/O/P 可獨立作答；觸控答案也正常。
- 暫停後計時停止，恢復後繼續；重新開始和回首頁有確認。
- 限時、KO、合作魔王的結束條件正常。
- 斷網後重新開啟仍可使用；沒有任何缺失的圖片、字型或音效資源。

## 可選：在新主機做程式檢查

若有安裝 Node.js，可執行：

```sh
node --check js/game.js
node --check js/questions.js
node --check js/audio.js
```

這只檢查語法；完整驗收仍需在瀏覽器中操作。
