# 專案名稱

九九怪獸大對決
Multiplication Monster Battle

請建立一個適合國小學生使用的「九九乘法雙人對戰遊戲」。

目標是讓兩位學生在同一台電腦、觸控螢幕或平板上，同時進行九九乘法答題，透過答題結果控制怪獸攻擊與血量。

整體必須是：

* 精美
* 可愛
* 有遊戲感
* 適合國小二～四年級
* 操作簡單
* 可離線執行
* 不需要登入
* 不需要伺服器
* 不依賴網路 API
* 支援 Windows、Mac、Chromebook、iPad 瀏覽器
* 最終可直接用 `index.html` 開啟

---

# 一、技術要求

優先使用：

* HTML5
* CSS3
* Vanilla JavaScript

若為了架構清楚可使用 Vite，但最終一定要能：

```text
直接離線執行
```

如果採用 Vite，請另外提供 build 後可直接使用的版本。

避免使用：

* React
* Vue
* Angular
* 外部資料庫
* CDN
* Google Fonts
* 網路圖片
* 網路音效
* 線上 API

所有資源都必須放在專案內。

專案完成後至少包含：

```text
/index.html
/css/style.css
/js/game.js
/js/questions.js
/js/audio.js
/assets/
README.md
```

若可以簡化成單一 HTML，也可以另外輸出：

```text
九九怪獸大對決_離線版.html
```

# 三、整體視覺風格

不要做成一般教育網站。

我要的是：

> 可愛怪獸 × 電玩競技場 × 兒童數學遊戲

參考氣氛：

* Pokémon 式角色對戰的清楚資訊架構
* Nintendo 式親切、明亮、可愛
* 手遊 Battle Arena 的生命值與攻擊回饋
* 但角色、圖示、UI 不可以直接模仿任何現有 IP

請建立原創視覺。

主要風格：

* 圓角
* 柔和漸層
* 明亮色彩
* 大按鈕
* 高辨識度
* 卡通風格
* 輕微 3D
* 避免過度幼兒化

背景可使用：

```text
天空
草原
岩石競技場
雲朵
遠山
彩旗
```

中央為怪獸戰鬥場地。

畫面不要過度塞滿資訊。

# 七、戰鬥系統

每位怪獸：

```text
HP = 100
```

一般答對：

```text
分數 +10
對方 HP -10
```

連續答對 3 題：

```text
Combo ×3
攻擊力提升
分數 +15
對方 HP -15
```

連續答對 5 題以上：

```text
Super Combo
分數 +20
對方 HP -20
```

答錯：

```text
Combo 歸零
自己 HP -5
```

不要因答錯扣除分數。

# 十二、防亂猜設計

# 四十一、測試

完成後請自行測試：

## 題目

* 答案是否正確
* 是否會出現重複答案
* 錯誤答案是否合理

## 雙人

* 是否可同時作答
* 玩家1是否影響玩家2題目
* 快速連續點擊是否產生 bug

## HP

* 是否可能低於 0
* 是否可能超過設定最大值

## Timer

* 是否會出現負數
* Pause 是否正確停止

## Result

* KO 是否正確
* 時間結束判定是否正確
* 平手是否正確

## Responsive

至少測試：

```text
1920×1080
1366×768
1024×768
iPad Landscape
```

# 最重要的設計原則

這不是：

「做一個九九乘法練習網頁」

而是：

> **做一款真的會讓國小學生想再玩一次的九九乘法雙人怪獸對戰遊戲。**

數學是核心。

怪獸、攻擊、Combo、音效、動畫，是讓學生願意持續練習的遊戲回饋。

請優先確保：

```text
好玩
清楚
流暢
公平
適合教室
完全離線
```
